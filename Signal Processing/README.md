## Trigonometric Fourier Transform
The continuous Fourier transform formula is given by
- Time domain to frequency domain: 
    - $$ \(F(\omega )=\int _{-\infty }^{\infty }f(t)e^{-i\omega t}dt\) $$
    - \(F(k)=\int _{-\infty }^{\infty }f(x)e^{-2\pi ikx}dx\) 
- Inverse Fourier transform: 
    - \(f(t)=\frac{1}{2\pi }\int _{-\infty }^{\infty }F(\omega )e^{i\omega t}d\omega \)
